Platform Scope Community Edition is an integrated cybersecurity analysis, network traffic forensics, and universal SIEM log evaluation platform designed to operate 100% offline (Air-Gapped) or containerized via Docker.

---

## 🚀 Quick Start (Docker)

```bash
git clone https://github.com/platformscope/platformscope.git
cd platformscope
docker compose up -d
```

Open your browser at `http://localhost:3000` to access the platform.
