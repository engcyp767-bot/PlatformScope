# ThreatScope MVP

منصة ويب محلية لتحليل ملفات XLSX وCSV الخاصة بتنبيهات الحماية، واستخراج الهاشات، وإثرائها عبر مصادر معلومات التهديدات، ثم إنشاء تقرير رسمي.

## التشغيل

يتطلب Python 3.11 أو أحدث، ولا يحتاج إلى تثبيت أي حزم خارجية.

من PowerShell:

```powershell
cd "C:\Users\Admin\Videos\New folder\threatscope"
python .\server.py
```

أو استخدم المشغّل الذي لا يتأثر بسياسة تنفيذ PowerShell:

```powershell
.\start.cmd
```

ثم افتح:

```text
http://127.0.0.1:8080
```

## تفعيل فحص الهاشات

اضبط المفاتيح في جلسة PowerShell قبل تشغيل الخادم:

```powershell
$env:VIRUSTOTAL_API_KEY = "YOUR_KEY"
$env:MALWAREBAZAAR_AUTH_KEY = "YOUR_KEY"
python .\server.py
```

لا يرسل النظام إلا الهاشات. لا يرفع ملف البيانات أو الملفات التنفيذية أو أسماء الأجهزة أو مساراتها.

## المخرجات

- لوحة تحليل عربية تفاعلية.
- تقرير HTML رسمي ومهيأ للطباعة أو الحفظ بصيغة PDF من المتصفح.
- تقرير Word رسمي مبني على قالب `XDR_VirusTotal_Hash_Report_AR.docx`.
- تقرير Excel بثلاث أوراق: الملخص، النتائج، ومعلومات الهاش.
- بصمة SHA-256 لملف المصدر.
- تخزين مؤقت لنتائج مزودي معلومات التهديدات لمدة 24 ساعة.

## الاختبارات

```powershell
python -m unittest discover -s tests -v
```

## الضوابط المطبقة

- حد رفع افتراضي 20 MB.
- قبول XLSX وCSV، مع دعم UTF-8 والترميزات العربية الشائعة والكشف التلقائي عن الفاصل.
- رفض ملفات XLSM/الماكرو، وفحص تضخم ZIP.
- عدم تشغيل صيغ Excel.
- قائمة ثابتة لنطاقات مزودي معلومات التهديدات لمنع الطلبات التعسفية.
- مفاتيح API من متغيرات البيئة فقط.
- حذف يدوي كامل لملف المهمة ونتائجها من الواجهة.
- اعتبار الهاش غير الموجود «غير معروف»، وليس «سليمًا».

## حدود MVP قبل النشر المؤسسي

الخادم مربوط افتراضيًا بعنوان `127.0.0.1` للاستخدام المحلي. قبل إتاحته لعدة مستخدمين يجب إضافة SSO/MFA، وصلاحيات أدوار، وTLS عبر Reverse Proxy، وسياسة احتفاظ آلية، وفحص مضاد للبرمجيات الضارة عند بوابة الرفع، وسجل تدقيق مركزي.
