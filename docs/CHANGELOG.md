4. **واجهة REST API v1 العامة ومولد OpenAPI 3.0 (`platform_core/api/`)**:
   - مدير مفاتيح API الآمن `APIKeyManager` بدعم تجزئة SHA-256 ونطاقات هرمية (`READ`, `INGEST`, `WRITE`, `ADMIN`) ومحدد معدل طلبات انزلاقي (Rate Limiter).
